# VANTA

VANTA is a local-first, supervised AI co-editor for DaVinci Resolve Studio. Its authoritative design is the repository's `Resolve Autopilot — Final Build Manual v2.docx`; the concise implementation map is in [`docs/VANTA_SPEC.md`](docs/VANTA_SPEC.md).

## Current state

The first prototype has been audited against the manual and is in a corrective Phase 1. Mission Control v0 reports gate evidence, read-only Resolve connection state, events, and reviewable run manifests. It does not claim inactive controls or Resolve edits are working. Resolve mutations remain unavailable in the normal app until a disposable-project gate run verifies the adapter. See [`docs/MANUAL_AUDIT.md`](docs/MANUAL_AUDIT.md), [`VANTA_IMPLEMENTATION_STATUS.md`](VANTA_IMPLEMENTATION_STATUS.md), and [`progress.md`](progress.md) for exact status.

## Setup

PowerShell from the repository root. The setup script selects Python 3.12 and creates an isolated `.venv`:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\scripts\setup.ps1
```

The script creates `.venv`, installs exact package versions from `requirements.lock`, then installs VANTA editable without resolving a second dependency set. It does not install Resolve, GPU drivers, models, or plugins.

Refresh the capability report:

```powershell
.\.venv\Scripts\python.exe scripts/phase0_probe.py
```

Start Mission Control on loopback:

```powershell
.\.venv\Scripts\python.exe -m uvicorn vanta.live.app:app --host 127.0.0.1 --port 8765
```

Open <http://127.0.0.1:8765>. SQLite state is stored under `data/` by default. Set `VANTA_DATA_DIR` to move it.

## Resolve integration

The installed Resolve scripting API is exposed only through `vanta/resolve/adapter.py`. The default adapter raises a clear unavailable error. Before a live implementation is enabled, follow the gate matrix in `capabilities.yaml` and test with a disposable project and new timelines. Set Resolve external scripting to Local; do not expose scripting over the network. Keep the project library backed up before a Resolve upgrade.

## Models and resources

VANTA has no default model downloads. Model/provider interfaces and a resource-aware scheduler are required before inference is enabled. On the current machine, first establish a CUDA-enabled runtime and actual GPU memory via `nvidia-smi`; benchmark one specialist at a time. AirLLM remains an optional experiment: layer streaming trades memory for repeated disk movement and can be very slow on Windows. It is not a substitute for the manual's quality/performance gates.

## Safety and current limitations

- No original media or Resolve project is modified by the capability probe.
- The UI currently displays gate state and event history; it cannot yet create or execute an edit.
- Gates G1–G16 have recorded statuses, but most require a running Resolve Studio session, test media, hand-built templates, and measured renders.
- The first real five-clip-plus-song timeline remains blocked on the verified adapter, actual source assets, and licensed music.
